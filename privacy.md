# Privacy Policy

This application is a personal integration used only by its owner.

## Google Drive Data

The application accesses Google Drive data through rclone solely for
personal file access, file management, and media playback.

Google Drive data is not sold, shared, or distributed to third parties.

## Data Storage

The application does not operate a public user database or collect data
from other users.

OAuth credentials are used only to authenticate the owner's Google
account.

## Contact

This application is maintained solely for personal use.
